10) Interactive GitHub OAuth login implementation
-------------------------------------------------

10.1 Schema update
- Modified:
  - src/modules/github/github.types.ts
- `authenticate_github` input extended with:
  - action: start | poll | pat
  - device_code (for poll)
  - token (PAT fallback)

10.2 GitHub service OAuth device flow
- Modified:
  - src/modules/github/github.service.ts
- Added GitHub OAuth device flow support:
  - startDeviceAuthorization()
    - POST /login/device/code
  - pollDeviceAuthorization(deviceCode)
    - POST /login/oauth/access_token
    - handles states:
      - pending
      - slow_down
      - expired
      - denied
      - authenticated
  - in-memory pending device code tracking
  - OAuth client credential env support:
    - GITHUB_OAUTH_CLIENT_ID (or GITHUB_CLIENT_ID fallback)
    - GITHUB_OAUTH_CLIENT_SECRET (or GITHUB_CLIENT_SECRET fallback)
- Updated token resolution behavior:
  - no token -> throws explicit auth-required McpError
  - fallback still supports env PAT if provided

10.3 GitHub tool auth flow behavior
- Modified:
  - src/modules/github/github.tools.ts
- authenticate_github now supports:
  - action="start": returns verification_uri, user_code, device_code, polling instructions
  - action="poll": returns pending/slow_down/expired/denied/authenticated status
  - action="pat": explicit PAT login fallback
- Added strict validation error using McpError when action=poll but device_code missing.

10.4 App config validation updated
- Modified:
  - src/app.module.ts
- Env validation now supports OAuth-first model with PAT fallback.

10.5 README OAuth docs
- Modified:
  - README.md
- Added:
  - required OAuth env vars
  - optional PAT fallback
  - step-by-step authenticate_github device flow instructions
